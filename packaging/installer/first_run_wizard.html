用户须知

Memo 是本地优先的记忆系统。继续安装即表示你了解以下内容：

本地数据数据库、配置和日志保存在你选择的数据根目录。
密钥安全API Key 只写入本机 config\.env，不会上传到 Memo 官网。
模型调用使用提取/总结能力时，相关文本会发送给你配置的模型服务商。
安装体积Full 版包含本地 Python Runtime；后续更新会优先使用 Lite 轻量包。
