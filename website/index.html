给多个 AI 工具共用的本地项目档案室。

Memo 是一个跨 Agent 的共享记忆系统，把散落在不同 AI 工具里的项目、知识、任务、偏好和来源线索，整理到同一个地方。

它不抢着替你做决定。它更像一个安静的协作账本，让 AI 在进入工作之前，先知道哪些东西已经聊过、想过、决定过。

AI 不缺一次性回答能力，缺的是连续工作里的账本。

项目是连续的，知识会积累，任务会迁移，决策有历史。可大多数 AI 工具只看见当前窗口。

Memo 想补上的，是长期协作里那间共享档案室。

01
少重复介绍背景项目路径、方案取舍、踩坑记录、部署信息，不必每次从头讲。
02
多个工具共享上下文支持 MCP 的 Agent 可以围绕同一个本地记忆库协作。
03
记忆可以被人治理重要的留下，临时的降权，错的标记，过期的归档。

Memo 现在能管理什么

记忆只是入口。真正有用的是围绕记忆展开的项目、知识、任务、偏好和来源管理。

01
项目管理

沉淀项目背景、阶段记录、技术选择、历史坑点和下一步计划。

02
知识管理

把对话里的概念、资料、经验和判断变成后续可以找回的知识线索。

03
任务管理

把“后面要做”“这里有风险”这类对话线索接住，形成可跟踪待办。

04
决策管理

记录方案取舍和历史判断，减少项目反复绕回老路。

05
偏好管理

让 AI 理解你的表达习惯、决策风格、审美边界和风险敏感点。

06
来源审计

每条记忆尽量保留出处。可追溯，才有资格被长期信任。

你大概可以怎么用它

先从一个很普通的流程开始，不需要把它想得太玄。

当前可用平台：Windows

首次安装推荐下载 Memo Full，包含 Memo 主程序、本地 Python Runtime 和必要依赖。macOS / Linux 暂时不是当前可用重点。

安装 Windows 版

用桌面助手启动本地 Memo 服务，打开 Dashboard。

配置模型 Key

本地数据库在电脑上，智能提取和分析由你配置的模型 API 增强。

接入常用 AI 工具

把 Memo 接到支持 MCP 的 Agent，让不同工具共享同一套长期上下文。

正常聊天，逐步沉淀

项目背景、知识线索、任务提醒、个人偏好，会随着使用逐步形成档案。

定期治理

打开 Dashboard 检查来源、归档噪音、修正不准的人格断言。

Early Co-test

如果你也受够了 AI 协作断片，欢迎一起共测。

Memo 还在早期阶段。现在更需要真实用户带着真实工作场景进来，把问题跑出来，把体验磨顺。
