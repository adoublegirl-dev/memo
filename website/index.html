FEATURES

Memo 可以做什么

01多 Agent 记忆流转

支持记忆导入、治理与应用，让不同 Agent 中的记忆流转起来。

02人格生成与更新

根据全部记忆和新增记忆生成及更新人格，让 AI 更懂你。

03记忆权重学习

根据记忆使用情况自动更新片段权重，让记忆真正活起来。

04MCP 工具接入

安装后可由 Agent 注册 MCP，随时同步和调用记忆。

05项目级会话归类

让记忆碎片按项目相互串联，不再散落在不同会话中。

06一句话创建待办

支持待办管理与提醒，把临时想法变成可跟进事项。

注意：上述部分能力需要 LLM 介入。若记忆内容较多，会消耗较多 Token，建议使用 DeepSeek v4-flash 或更便宜的模型。
VALUE

Memo 的价值

Memo 的价值在于持续积累。项目越复杂、周期越长、参与的 AI 工具越多，它越适合成为一个可信赖、可管理的本地上下文底座。

PRIVACY

你的记忆，只属于你

Memo 不会拿走你的记忆。它们会直接存储在你的电脑本地，由你自己管理。

FAQ

常见问题

我应该选择哪个数据目录？

建议存放在非 C 盘的目录下，最好创建一个单独的文件夹管理它们。

是否必须配置 LLM？

不是必须。但为了提升记忆使用和人格生成质量，建议配置 LLM，并尽量选择便宜的模型。如果安装时没有配置模型和 Key，可以在安装 MCP 后让 Agent 帮你在 .env 文件中配置。
